# Grupo Arcádia — Site estático

## Como publicar na Vercel
1. Extraia este ZIP.
2. Envie a pasta para um repositório no GitHub.
3. Na Vercel, importe o repositório.
4. Como é um site estático, não precisa instalar dependências nem executar build.
5. A Vercel deve detectar o `index.html` automaticamente.

## Arquivos
- index.html
- style.css
- script.js
- assets/

O gráfico é visual/demonstrativo e está preparado para ser substituído futuramente por dados reais vindos de uma API ou banco de dados.
